# 토템 나침반 (Totem Compass)

휴대폰 신호가 없어도 서로를 찾을 수 있는 작은 나침반 두 개.
토템 두 대가 LoRa 무선으로 위치를 주고받아서, 화면에 **상대가 있는 방향과 거리**를 화살표로 보여 줍니다.
축제, 캠핑, 등산처럼 사람이 많거나 통신이 잘 안 되는 곳에서 일행을 찾을 때 쓰려고 만들었습니다.

- 상대 방향 화살표 + 거리 (GPS + 나침반 센서)
- GPS가 안 잡히는 실내에서는 **신호 세기**로 가까워지는지 안내
- 버튼 하나로 "보고싶어" 보내기, 받으면 화면과 LED로 알림
- **실내 찾기**: GPS가 안 될 때 두 토템이 1초마다 신호를 주고받으며 "가까워져요 / 멀어져요"를 알려 주고, 제자리에서 한 바퀴 돌면 신호가 센 쪽을 화살표로 보여 줌. 상대 토템을 깜박이게 할 수도 있음
- 화면 맨 위에 **내 이름** (앱에서 설정, 상대 토템에도 보임)
- 폰 지도 앱 [totem-map](https://github.com/N00BWORLD/totem-map)과 블루투스 연결: 지도에서 상대 위치·경로 보기, 만남 장소 지정, 메시지(보고싶어 / 어디야? / 곧 갈게), 실내에서 폰 위치 빌려주기
- 멀어지면 알림, 화면 자동 꺼짐 (앱에서 설정)
- 토템끼리 주고받는 내용은 **AES-128-GCM으로 암호화**. 같은 키를 넣은 토템끼리만 서로 보입니다.

## 필요한 것 (한 대 기준, 두 대 필요)

| 부품 | 비고 |
|---|---|
| Heltec WiFi LoRa 32 **V3.1 / V3.2** | ESP32-S3 + SX1262 + OLED 내장. 미국·한국은 **863-928MHz** 버전 |
| BNO055 나침반 모듈 | I2C (Adafruit 등) |
| GPS 모듈 | NMEA 출력 9600bps (u-blox NEO-6M/M8N 등) |
| 리튬폴리머 배터리 3.7V | 보드 배터리 커넥터(JST 1.25) |
| 868/915MHz 대역 안테나 | 보드에 포함 |

## 배선

| 부품 | 모듈 핀 | 보드 GPIO |
|---|---|---|
| BNO055 | SDA / SCL | **4 / 5** |
| BNO055 | VIN / GND | Ve(3.3V) / GND |
| GPS | TX → | **6** (보드 RX) |
| GPS | VCC / GND | Ve(3.3V) / GND |

OLED, LoRa, 배터리 측정, LED, PRG 버튼은 보드에 내장되어 있습니다.
Ve 핀은 펌웨어가 켜는 3.3V 전원입니다(GPIO36).
배선을 다르게 했다면 [`tools/probe`](tools/probe/probe.ino) 스케치를 먼저 올리세요. 시리얼 모니터에 BNO055와 GPS가 연결된 핀이 나오고, 그 값을 [`config.h`](config.h)에 넣으면 됩니다.

## 설치

### 1. 개발 환경
Arduino IDE 2.x 또는 [arduino-cli](https://arduino.github.io/arduino-cli/)를 씁니다.

1. 보드 매니저 URL 추가: `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. 보드 패키지 **esp32 by Espressif** 설치 (3.3.x에서 확인)
3. 라이브러리 **RadioLib**, **U8g2** 설치
4. Windows에서 보드가 COM 포트로 안 잡히면 Silicon Labs **CP210x 드라이버**를 설치하세요.

### 2. 암호 키 만들기 (중요)
[`secrets.example.h`](secrets.example.h)를 `secrets.h`로 복사하고, 키를 무작위 16바이트로 바꿉니다. 만드는 방법은 파일 안에 있습니다.
**짝이 되는 두 토템에는 같은 `secrets.h`를 넣어야 합니다.** 키는 남에게 알려주지 마세요. 키가 같으면 위치를 볼 수 있습니다.

### 3. 업로드
- Arduino IDE: 보드 **Heltec WiFi LoRa 32(V3)**, 포트 선택 후 업로드
- arduino-cli:
  ```
  arduino-cli compile --fqbn esp32:esp32:heltec_wifi_lora_32_V3 --upload -p COM3 .
  ```
  (COM3 자리에 내 포트. macOS/Linux는 `/dev/ttyUSB0` 같은 이름)

처음 컴파일은 10분 넘게 걸릴 수 있습니다.

## 사용법

**PRG 버튼**
- 짧게 누르기: 다음 화면 (상대 → 실내 찾기 → 만남 장소 → GPS → 시스템), 알림 닫기
- 길게 누르기(약 1초):
  - 상대 화면: "보고싶어" 보내기
  - 실내 찾기 화면: 찾기 시작 (찾는 중이면 방향 다시 재기). 3분 뒤 자동으로 꺼짐
- 화면이 꺼져 있을 때 누르면 화면만 켜집니다.

**나침반 보정**: 처음 켜면 토템을 8자로 몇 번 돌리고, 잠시 여러 방향으로 놓아 두세요.
보정이 끝나면 보정값이 자동으로 저장되고, 다음에 켤 때 다시 불러옵니다.

**폰 앱**: 안드로이드 크롬에서 [totem-map](https://github.com/N00BWORLD/totem-map)을 열고 연결을 누르면 `TOTEM-xxxx`가 보입니다.

## 통신 규격

다른 앱이나 펌웨어를 만들 때 참고하세요. 모든 숫자는 little-endian입니다.

### LoRa (토템 ↔ 토템)
- 지역은 [`config.h`](config.h)의 `REGION_US` / `REGION_KR` 중 하나 (두 토템이 같아야 함). sync word 0x12, CR 4/5. 보내기 전에 채널이 비었는지 확인(CAD)
  | 지역 | 주파수 | 대역폭 | SF | 출력 |
  |---|---|---|---|---|
  | 미국 (기본) | 919.0 MHz | 500 kHz | 11 | 17 dBm |
  | 한국 | 922.1 MHz | 125 kHz | 9 | 13 dBm |
- 15~18초마다 한 번 송신 (배터리 절약). 메시지를 보내거나 만남 장소를 바꾸면 바로 송신. 어느 한쪽이라도 실내 찾기 중이면 둘 다 1.2~1.6초마다
- 59바이트 프레임: 헤더 11 + 암호문 40 + 태그 8 (v4.1부터. v4.0과는 서로 안 보임). 자세한 형식은 [`protocol.h`](protocol.h)
- 다른 나라에서 쓰려면 [`config.h`](config.h)에 그 나라 규정에 맞는 지역을 추가하세요.

### BLE (토템 ↔ 앱)
서비스 `6e7a0001-7c3a-4b8e-9f2d-544f54454d31`

**STATUS** `6e7a0002-…` (read / notify, 78바이트. 0~41만 읽어도 됨)

| 오프셋 | 형식 | 내용 |
|---|---|---|
| 0 | u8 | 버전 (3) |
| 1 | u8 | 플래그: 1 내 위치 있음, 2 상대 신호 받음, 4 상대 위치 있음, 8 만남 장소 있음, 16 나침반 정상, 64 폰 위치 사용 중, 128 충전 중 |
| 2, 6 | i32 | 내 위도, 경도 (×1e7) |
| 10 | u16 | 방위 (도, 진북) |
| 12, 13 | u8 | 내 위성 수, 배터리 % |
| 14, 18 | i32 | 상대 위도, 경도 |
| 22 | u16 | 상대 신호 받은 지 몇 초 |
| 24 | i16 | 상대 신호 세기 (dBm) |
| 26, 27 | u8 | 상대 위성 수, 배터리 % |
| 28, 32 | i32 | 만남 장소 위도, 경도 |
| 36 | u8 | 받은 메시지 카운터 (바뀌면 새 메시지) |
| 37 | u8 | 보낸 메시지 상태: 0 없음, 1 보내는 중, 2 전달됨 |
| 38 | u8 | 받은 메시지 종류 |
| 39 | u16 | 멀어지면 알림 거리 (m, 0 끔) |
| 41 | u8 | 화면 자동 꺼짐 (분, 0 끔) |
| 42 | u8 | 찾기: 1 찾는 중, 2 상대도 찾는 중, 4 방향 재기 끝, 8 상대 충전 중 |
| 43 | i16 | 상대 신호 평균 (dBm) |
| 45 | i8 | 1 가까워짐, -1 멀어짐, 0 그대로 |
| 46 | u16 | 신호가 센 방향 (도, 진북) |
| 48, 49 | u8 | 센 쪽과 약한 쪽 차이 (dB), 잰 방향 수 (12칸 중) |
| 50, 52 | u16 | 내 위치 오차, 상대 위치 오차 (m) |
| 54 | 12바이트 | 내 이름 (UTF-8) |
| 66 | 12바이트 | 상대 이름 (UTF-8) |

**CMD** `6e7a0003-…` (write)

| 첫 바이트 | 뒤 내용 | 동작 |
|---|---|---|
| 1 | lat i32, lon i32 | 만남 장소 지정 (상대 토템에도 전달) |
| 2 | | 만남 장소 지우기 |
| 3 | type u8 | 메시지 보내기 (1 보고싶어, 2 어디야?, 3 곧 갈게, 4 상대 토템 깜박이게) |
| 4 | farM u16, screenMin u8 | 설정 저장 |
| 5 | lat i32, lon i32, 정확도 u16 | 폰 위치 빌려주기 (15초 동안 유효) |
| 6 | 0 / 1 / 2 | 실내 찾기 끄기 / 켜기(3분, 다시 보내면 연장) / 방향 다시 재기 |
| 7 | 이름 UTF-8 (12바이트까지) | 내 이름 저장 |

## 파일

| 파일 | 내용 |

| `totem-firmware.ino` | 본체: LoRa, BLE, 화면, 버튼 |
